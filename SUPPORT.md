# LAGSHIFT Support

## Before asking for help

1. Install the newest release from the official
   [Releases page](https://github.com/OmniArcLabs/LAGSHIFT/releases/latest).
2. Read [`QUICKSTART.md`](QUICKSTART.md) and the known limitations in
   [`RELEASE_NOTES.md`](RELEASE_NOTES.md).
3. Use the in-app disconnect and restore action before changing Windows network
   settings manually.
4. Confirm that the issue is reproducible on the current network.

## Public support

Use the structured
[issue forms](https://github.com/OmniArcLabs/LAGSHIFT/issues/new/choose) for bugs
and focused feature requests. Include the LAGSHIFT version, Windows version,
network type, visible behavior, and safe reproduction steps.

Never publish passwords, account tokens, configuration links, public IP
addresses, or unredacted diagnostic archives.

## Security reports

Security vulnerabilities must be reported through
[GitHub Private Vulnerability Reporting](https://github.com/OmniArcLabs/LAGSHIFT/security/advisories/new),
not a public issue.

## Support boundary

LAGSHIFT is a local-first gaming and supported-application connectivity tool. It
does not provide general-purpose VPN access, imported tunnel subscriptions, or a
guaranteed route on every ISP. OMNIARC cannot provide support for bypassing laws,
third-party terms, account restrictions, or unrelated filtering.
